# 🚀 Protótipo Advocacia

[![Status](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen)](https://github.com/rita-cassia-developer/prototipo-advocacia)

## 📝 Descrição do Projeto

Este projeto é um **protótipo de website para um escritório de advocacia**, desenvolvido com o objetivo de aprimorar habilidades em HTML, CSS, responsividade, acessibilidade e boas práticas de desenvolvimento web. Ele simula a estrutura de um site profissional, apresentando seções como serviços, equipe e contato.

## ✨ Funcionalidades

- **Design Responsivo:** Layout adaptável para diferentes dispositivos (desktops, tablets e smartphones).
- **Estrutura Semântica:** Utilização de HTML5 para uma organização clara e acessível do conteúdo.
- **Acessibilidade (WCAG):** Implementação de práticas para garantir que o site seja utilizável por todos.
- **Boas Práticas de Desenvolvimento:** Código limpo e organizado, seguindo padrões da indústria.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação do conteúdo e semântica da página.
- **CSS3:** Estilização e responsividade do layout.
